# Task 4 report — operation timing and diagnostics dashboard

## Result

Operation detail now returns phase aggregates as `phases` and returns `events` only when event rows exist. The reader uses the schema version before accessing the v10-only tables, so older supported journals return an empty phase list and omit events. Connection event detail is parsed defensively and exposes only the allowlisted client connection id and truncation count. The operation page displays phase count, total, max, and share of wall time, plus a collapsed connection-event list with offsets, durations, outcomes, error numbers, connection ids, and an omitted-event count.

The existing compare detail and session annotation paths remain in the same operation/session response and are covered by the focused contract tests.
